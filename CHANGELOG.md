# Changelog

## 1.1.0

- Added contextual frontend AI assistance for code examples: Explain Code, Explain Line, Ask about this code, and Check Your Understanding.
- Added a hardened public reader AI boundary with server-side provider execution, validation, request-size limits, same-site checks, privacy-preserving rate limiting, and normalized provider errors.
- Added Reader Insights for article-level interactions and reusable Code Examples.
- Added concept-level Code Example analytics across multiple articles.
- Added AI Editorial Insights based on deterministic reader analytics.
- Preserved canonical/reference Code Example identity and canonical editing from article references.
- Added the floating frontend AI Assistant with discoverability reminders, reduced-motion support, and contextual Code Example highlighting.
- Refined Reader Insights dashboard hierarchy, loading/generating states, tables, metrics, and AI surfaces.
- Updated the build configuration so all block source assets, including the floating assistant, are compiled into tracked production assets.
